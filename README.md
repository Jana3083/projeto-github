# projeto-github

Projeto Workshop GitHub COTI Informática

## 📋 Descrição

Este é um projeto desenvolvido durante um workshop de GitHub na **COTI Informática**. O projeto é uma aplicação web interativa que demonstra os conceitos fundamentais de desenvolvimento front-end usando as três principais linguagens da web.

## 🛠️ Tecnologias Utilizadas

### **HTML (HyperText Markup Language)**
- Responsável pela estrutura e conteúdo da aplicação
- Define os elementos semânticos da página
- Garante acessibilidade e organização do código

### **CSS (Cascading Style Sheets)**
- Responsável pelo estilo visual e layout da aplicação
- Implementa responsividade para diferentes tamanhos de tela
- Define cores, tipografia e animações

### **JavaScript (JS)**
- Responsável pela interatividade e lógica dinâmica
- Manipula o DOM (Document Object Model)
- Implementa funcionalidades e eventos da aplicação

## 🚀 Como Abrir e Rodar o Projeto no VSCode

### Pré-requisitos
- [VSCode](https://code.visualstudio.com/) instalado
- Extensão recomendada: **Live Server** (opcional, mas facilita muito!)

### Passo a Passo

#### 1️⃣ **Clonar o Repositório**
```bash
git clone https://github.com/Jana3083/projeto-github.git
cd projeto-github
```

#### 2️⃣ **Abrir no VSCode**
```bash
code .
```

#### 3️⃣ **Executar o Projeto**

**Opção A: Usando Live Server (Recomendado)**
- Clique com o botão direito no arquivo `index.html`
- Selecione **"Open with Live Server"**
- O navegador abrirá automaticamente com a aplicação

**Opção B: Abrir Diretamente no Navegador**
- Localize o arquivo `index.html` no explorador de arquivos
- Clique duas vezes ou arraste para o navegador
- Ou use o atalho: `Ctrl+O` (Windows/Linux) ou `Cmd+O` (Mac) no navegador

**Opção C: Usar um Servidor Local (Python)**
```bash
# Python 3.x
python -m http.server 8000

# Depois acesse: http://localhost:8000
```
