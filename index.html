A base de tudo

Antes de usar,
entenda a diferença.

Git e GitHub trabalham juntos, mas não são a mesma coisa. Pense no Git como o motor e no GitHub como a garagem compartilhada.

⎇01 / ferramenta

Git

É o sistema de controle de versão que vive no seu computador. Ele registra cada mudança no projeto para você poder voltar, comparar e experimentar sem medo.

Local · histórico · controle
⌘02 / plataforma

GitHub

É a plataforma online que hospeda repositórios Git. Ela adiciona colaboração, revisão de código, automações e uma comunidade global.

Nuvem · equipe · comunidade
